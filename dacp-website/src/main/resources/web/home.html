See what is happening.

Node dashboards distinguish direct client jobs from Union subjobs and place operator step records inside job details. DAGs separate upstream output interfaces from local execution, with horizontal and vertical dependency or swimlane layouts. Mouse zoom is locked by default so the wheel scrolls the page; unlock it to zoom the graph. Jobs have readable names alongside generated IDs. Node and Union lists use matching columns for names, IDs, sources, types, states, start times and durations. Full job definitions, dispatched subjobs, policies and variable files use YAML, including local inputs, remote producer identities and authorized output consumers. Union topology links show cumulative task payload and transfer rates. The operator repository provides searchable operators, version details, source archives and downloads.

Follow a distributed execution

Start with a user workflow whose inputs reference upstream task ports. Union dispatches local connections as task:port and remote inputs as locations containing origin, task, port and producer_identity. Only remote output readers need output_routes with consumer_identity. Stream representations come from stream headers.

Inspect the node topology and complete Sub-job definition, then expand Operator step records for individual states and durations. Execution history is separate from output materialization: retained job metadata does not imply saved result payloads.

# 文档归属

[English](documentation.md)

每个主题只有一个可编辑的维护源。README 介绍项目、提供最小快速入门并链接详细指南，不重复完整手册。

| 所属项目 | 权威内容 |
|---|---|
| dacp-codex | 数据服务、客户端、Union、代理、安全、部署和集成 |
| xstream-codex | 引擎、Job YAML、执行策略、Designer、数据 SDK 和算子开发 |
| xstream-operator-repository | 仓库 API、提交审核、管理、浏览和运行环境目录 |
| 官网项目 | 产品介绍、下载、截图、网站部署和演示环境运维 |

英文 Markdown 和完整中文翻译共同保存在所属项目中。模块 README 描述模块专有的配置；公共概念放在项目指南中。跨项目集成只说明自身行为，并引用所属项目的参考文档，不复制参考说明。

官网根据这些源文档的版本化快照生成完整英文手册。快照和 HTML 是构建输入／输出，不是独立编写位置。先修改所属项目，再在同一次变更中刷新快照并重新生成 HTML。SOURCE 记录源提交，SNAPSHOT.json 记录工作区内容的精确摘要。生成时拒绝直接修改的快照。仅刷新文档需要源项目目录，网站运行不需要。

首页简短介绍和快速入门示例可以保留。详细配置、API 契约和示例仅在权威源维护。修改示例时同步更新调用方及中英文引用。校验生成页面的链接，并将快照与源变更一起审阅。
